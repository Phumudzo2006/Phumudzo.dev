Journal Reference System

A desktop application for managing academic journal references and citation.

Built to strengthen my software development, data management and object-oriented programming skills.

Project Overview

The Journal Reference system is a C++ destop application developed using QT Creator. It allow users to store, organize, search and manage academic journal references efficiently through a user friendly interface

C++ Qt Creater Desktop Application OOP Reference management

Problem & Motivation

Managing academic references manually can be time-consuming and error-prone. this project that simplifies the process of storing, organizing, and retrieving journal references for research purposes.

Why I Built This Project

built this project to improve my understanding of desktop application development,oop and data management using C++ and QT Creator, also for school perposes.

Key Features

  • Add new Journal references
  • Edit existing references information
  • Delete reference
  • Search references by title, author or publication year
  • store journal details including author, title, volume, and DOI
  • User Friendly Qt-Based interface

Technologies Used

  • C++
  • Qt Creator
  • Qt Widgets
  • signals & slots
  • Object-Oriented Programming

Challenges Faced

  • Designin an efficient data structure for Journal references
  • Keeping the user interface synchronized with stored data
  • Implementing search functionality across multiple fields
  • separating application logic from user interface components

What I Learned

  • Desktop applications development using Qt
  • Event-driven programming
  • object-oriented softwere designing
  • CRUD operations and data manegement
  • Building maintainable C++ application
