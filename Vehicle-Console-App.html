Vehicle Console App (C++)

A console-based vehicle management system developed using C++ and Object-Oriented Programming principles.

Built to strengthen my software engineering, problem-solving, and object-oriented programming skills.

Project Overview

Vehicle Console App is a C++ console application designed to manage vehicle records through a simple menu-driven interface. The project demonstrates object-oriented programming concepts, data management, and user interaction through the command line.

C++ OOP Console Application Data Structures Software Development

Problem & Motivation

Managing vehicle information manually can become inefficient and difficult as records grow. This project provides a structured approach to storing, viewing, and managing vehicle data while demonstrating core software engineering concepts.

Why I Built This Project

I created this project to strengthen my understanding of Object-Oriented Programming and software design using C++.

The application allowed me to practice building a complete software solution that manages data efficiently while maintaining clean, organized, and reusable code.

How to Run the Project

# Clone Repository
git clone https://github.com/Phumudzo2006/Vehicle-Console-App.git
# Navigate into folder
cd Vehicle-Console-App
# Compile
g++ *.cpp -o VehicleConsoleApp
# Run
./VehicleConsoleApp
